# User stories (MoSCoW)

## Must (v1.0)
- As a PhD student I can add a "Method" text field and a "Relevance" 1–5 field so I can rate papers as I read.
- As a user I can open my "Chapter 2" collection as a table and type directly into cells.
- As a user I can sort by Relevance and see my top papers first.
- As a user I can export the table to Excel to send my supervisor.
- As a user my fields sync to my laptop because they live in Zotero's own data.
- As a user with Better BibTeX installed, nothing in my Extra field breaks.

## Should (v1.1)
- Per-column filters; saved views; select fields with colored options.
- Templates for literature review and systematic review.
- Show a field as a column in the normal Zotero item list.

## Could (v1.2+)
- AI: "fill this column from the PDF" with credits.
- Group-library shared schema.
- Import an existing Excel matrix and map columns to fields.

## Won't (v1)
- Storage/sync hosting; mobile; charts.
